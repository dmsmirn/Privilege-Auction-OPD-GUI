# Контракт API

Этот документ описывает, как фронтенд (React) общается с бэкендом (C++). Любые изменения здесь должны быть согласованы с фронтендом.

## 1. Общие правила

- **Адрес сервера:** `http://localhost:8080`
- **Формат данных:** всегда JSON (`application/json`).
- **Названия полей:** camelCase (`basePrice`, `createdAt`).
- **Даты:** строка ISO 8601 в UTC, например `"2026-11-05T20:00:00Z"`.
- **Награда:** считает сервер по формуле библиотеки `pa::Engine`: `price = basePrice + M × k1 × k2 × k3 − штраф`, где M — множитель ранга (D/C/B/A → 1/3/5/10). Баллы — целые числа. Фронтенд награду не считает.
- **CORS:** сервер разрешает запросы с любого адреса (`Access-Control-Allow-Origin: *`) и отвечает на `OPTIONS`.

## 2. Формат ошибок

Любая ошибка возвращается в таком виде:

```json
{
  "error": "not_found",
  "message": "Задача с таким id не найдена"
}
```

- `error` — короткий код латиницей (по нему работает фронтенд).
- `message` — понятный текст для человека.

| HTTP-код | `error` | Когда |
|---|---|---|
| 400 | `bad_request` | неправильное тело запроса |
| 400 | `bid_too_low` | ставка не выше текущей |
| 400 | `bid_over_balance` | ставка больше баланса пользователя |
| 401 | `unauthorized` | пользователь не определён |
| 404 | `not_found` | задача или лот не найдены |
| 409 | `lot_closed` | торги по лоту уже закончились |

## 3. Типы данных

### Task (задача)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | например `"task-1"` |
| `title` | string | название |
| `description` | string | описание |
| `basePrice` | number | базовая цена (диапазон зависит от ранга: D 0–50, C 51–200, B 201–500, A от 501) |
| `rank` | string | ранг задачи: `"D"`, `"C"`, `"B"` или `"A"` |
| `k1` | number | K1 «время»: `min(3, Тплан / Тфакт)`, в срок = 1 |
| `k2` | number | K2 «силы»: объём, сложность, риски (1–5) с весами |
| `k3` | number | K3 «попытки»: `1 − 0.15 × (n − 1)` |
| `price` | number | награда (считает сервер) |
| `status` | string | `"open"`, `"in_progress"` или `"done"` |
| `createdAt` | string | дата создания |

### Lot (лот)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | например `"lot-1"` |
| `title` | string | название |
| `currentBid` | number | текущая лучшая ставка |
| `endsAt` | string | когда заканчиваются торги |
| `bids` | Bid[] | список ставок |

### Bid (ставка)

| Поле | Тип | Описание |
|---|---|---|
| `userId` | string | кто сделал ставку |
| `amount` | number | сумма |
| `createdAt` | string | когда сделана |

### User (пользователь)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | например `"user-1"` |
| `balance` | number | баланс |
| `workload` | number | загрузка (используется в `k2`) |

## 4. Адреса

### 4.1. Список задач

- **Метод и адрес:** `GET /api/tasks`
- **Ответ 200:**

```json
[
  {
    "id": "task-2",
    "title": "Сделать отчёт",
    "description": "Подготовить квартальный отчёт по проекту",
    "basePrice": 300,
    "rank": "B",
    "k1": 1.2,
    "k2": 2.7,
    "k3": 1,
    "price": 316,
    "status": "open",
    "createdAt": "2026-11-01T10:00:00Z"
  }
]
```

### 4.2. Одна задача

- **Метод и адрес:** `GET /api/tasks/:id`
- **Ответ 200:** один объект Task (как в 4.1).
- **Ошибки:** 404 `not_found`.

### 4.3. Список лотов

- **Метод и адрес:** `GET /api/lots`
- **Ответ 200:**

```json
[
  {
    "id": "lot-1",
    "title": "Выбор фильма на вечер",
    "currentBid": 100,
    "endsAt": "2026-11-05T20:00:00Z",
    "bids": [
      { "userId": "user-2", "amount": 100, "createdAt": "2026-11-04T18:30:00Z" }
    ]
  }
]
```

### 4.4. Один лот

- **Метод и адрес:** `GET /api/lots/:id`
- **Ответ 200:** один объект Lot (как в 4.3).
- **Ошибки:** 404 `not_found`.

### 4.5. Сделать ставку

- **Метод и адрес:** `POST /api/lots/:id/bids`
- **Тело запроса:**

```json
{ "amount": 120 }
```

- **Ответ 200:** обновлённый лот (объект Lot, в `bids` уже есть новая ставка, `currentBid` равен `120`).
- **Ошибки:**
  - 400 `bad_request` — в теле нет `amount` или это не число;
  - 400 `bid_too_low` — `amount` не больше `currentBid`;
  - 400 `bid_over_balance` — `amount` больше баланса пользователя;
  - 404 `not_found` — лота нет;
  - 409 `lot_closed` — торги закончились.

### 4.6. Текущий пользователь

- **Метод и адрес:** `GET /api/me`
- **Ответ 200:**

```json
{ "id": "user-1", "balance": 150, "workload": 2 }
```

- **Ошибки:** 401 `unauthorized`.

### 4.7. Предварительный расчёт цены (для демо-панели)

- **Метод и адрес:** `POST /api/price/preview`
- **Тело запроса:**

```json
{ "basePrice": 300, "rank": "B", "k1": 1.2, "k2": 2.7, "k3": 1 }
```

- **Ответ 200:** `basePrice + M × k1 × k2 × k3`, округлено до целого. `rank` необязателен (по умолчанию D):

```json
{ "price": 316 }
```

- **Ошибки:** 400 `bad_request` — не хватает полей или они не числа.
